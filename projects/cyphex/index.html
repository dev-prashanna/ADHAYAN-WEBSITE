CYPHEX

Headless ESP32 firmware for WiFi and Bluetooth security testing, controlled through Serial, BLE, or WiFi.

GitHub ↗ All projects

ESP32 security testing

CYPHEX is a CLI-focused fork of ESP32 Marauder by JustCallMeKoko. It provides WiFi and Bluetooth security testing without requiring a display or SD card.

The firmware supports control through Serial, BLE, and WiFi. The repository includes PlatformIO configuration, flashing tools, and command documentation.
